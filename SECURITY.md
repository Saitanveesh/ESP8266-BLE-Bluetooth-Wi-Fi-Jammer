# Security and responsible use

This repository contains historical experimental code involving 2.4 GHz RF interference. The code is not validated, packaged, or approved for deployment.

**Do not use the project to disrupt other people's Wi-Fi, Bluetooth, or other wireless services.** Restrict any legitimate laboratory work to conditions and facilities authorised for the specific activity, with suitable shielding, supervision, and compliance review.

Do not assume that software standby states electrically disable all transmissions. Independently verify safe shutdown and power behaviour in any hardware assessment.

If you discover an exposed credential, dependency vulnerability, unsafe electrical condition, or inaccurate safety claim, contact the maintainer privately through the contact methods available on their [GitHub profile](https://github.com/Saitanveesh). Do not post sensitive information publicly in an issue.

This project is not a substitute for RF safety, electrical engineering, or regulatory advice.
